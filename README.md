# 🎨 ColorCraft

**Generate • Explore • Save Beautiful Color Palettes**

ColorCraft is a modern color palette generator built with **HTML, CSS, and Vanilla JavaScript**. It helps designers and developers create, customize, and save beautiful color combinations with an intuitive and responsive interface.

https://alokdevops43.github.io/colorcraft/

## ✨ Features

* 🎲 Generate random color palettes
* 🔒 Lock individual colors while generating new palettes
* 📋 Copy HEX, RGB, and HSL values with one click
* 🌈 Generate linear and radial gradients
* 🎯 Color contrast checker
* 💾 Save favorite palettes using Local Storage
* 📤 Export palettes as CSS variables and JSON
* 🌙 Dark mode support
* 📱 Fully responsive design
* ⚡ Fast and lightweight

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
